# AI Resume Analyzer

## Overview
AI Resume Analyzer is a machine learning project that analyzes resumes against job descriptions. It calculates an ATS score, detects missing skills, and provides AI-based suggestions to improve the resume.

## Features
- Upload PDF/DOCX resume
- Extract resume text
- Extract technical skills
- Compare with job description
- Calculate ATS score
- Detect missing skills
- AI-powered resume suggestions

## Tech Stack
- Python
- Streamlit
- spaCy
- Sentence Transformers
- Scikit-learn
- PyMuPDF
