# ATS Resume Rules

## What is an ATS?

An Applicant Tracking System (ATS) is software used by companies to scan, parse, and rank resumes before they reach a recruiter.

## ATS Best Practices

- Use a simple and clean layout.
- Use standard section headings such as Education, Experience, Projects, Skills, and Certifications.
- Keep the resume to one or two pages.
- Use reverse chronological order for experience and education.
- Save the resume as PDF unless the company requests another format.
- Use readable fonts such as Calibri, Arial, or Times New Roman.
- Keep font size between 10 and 12 points.
- Include keywords from the job description naturally.
- Quantify achievements using numbers whenever possible.
- Include relevant technical skills.

## Avoid

- Tables
- Text boxes
- Images
- Icons
- Headers and footers containing important information
- Fancy graphics
- Multiple columns

## Important Resume Sections

- Contact Information
- Professional Summary
- Skills
- Experience
- Projects
- Education
- Certifications
- Achievements

## Tips

Good Example

Developed a customer churn prediction model using XGBoost achieving 94% accuracy.

Bad Example

Worked on a machine learning project.

## Common ATS Mistakes

- Missing keywords
- Spelling mistakes
- Inconsistent formatting
- Using uncommon section titles
- Listing irrelevant skills
- Writing vague project descriptions
