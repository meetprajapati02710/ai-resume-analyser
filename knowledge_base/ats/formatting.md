# Resume Formatting Guidelines

## Recommended Layout

- Keep the resume to one page if you have less than 5 years of experience.
- Use two pages only if necessary.
- Maintain consistent spacing and margins.
- Use bullet points instead of long paragraphs.
- Align all headings consistently.

## Fonts

Recommended fonts:

- Calibri
- Arial
- Helvetica
- Times New Roman

Font Size:

- Heading: 14–16 pt
- Body: 10–12 pt

## Resume Sections Order

1. Contact Information
2. Professional Summary
3. Skills
4. Experience
5. Projects
6. Education
7. Certifications
8. Achievements

## Bullet Points

Good Example

• Built an AI Resume Analyzer using Python, Streamlit, and GPT, improving ATS matching by 30%.

Bad Example

• Worked on AI project.

## White Space

- Keep enough spacing between sections.
- Avoid cluttered layouts.

## File Format

Preferred:

- PDF

Alternative:

- DOCX (if requested)

## Colors

Use minimal colors.

Recommended:

- Black
- Dark Blue

Avoid bright colors and decorative backgrounds.

## Common Formatting Mistakes

- Multiple columns
- Large images
- Fancy graphics
- Inconsistent font sizes
- Too many colors
- Very small text
- Long paragraphs
