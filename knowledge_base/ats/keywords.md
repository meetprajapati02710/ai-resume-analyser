# Resume Keywords

## Why Keywords Matter

Most Applicant Tracking Systems search resumes for keywords that match the job description.

## How to Use Keywords

- Read the job description carefully.
- Include technical skills naturally.
- Match the terminology used by the employer.
- Avoid keyword stuffing.
